# お便り用撮影アプリ

## URL

既存のGAS WebアプリURLの末尾に `?view=camera` を付けて開きます。

iPhoneで画面内カメラを維持して連続撮影する場合は、同じ `camera.html` をHTTPSの独立ページとして公開します。ファイルは実行環境を自動判別し、独立ページでは画面内カメラとHTTP送信、GAS内では `google.script.run` を使用します。独立ページを公開する前に、`コード.gs` の `doPost`・JSONP処理を含む版をGASへ再デプロイしてください。

## 保存先

既存の園だより写真フォルダ配下に、次の構造で保存します。既存の同名フォルダがあれば再利用します。

`西暦年MM月 / クラス / 活動名 / 写真ファイル`

保存時に「柏こども園報告フォーム（回答）」の「フォームの回答 1」へ、既存規則に合わせて A列=撮影日時、C列=クラス、E列=活動名、F列=写真URLを記録します。既存の空き列は変更しません。選択した西暦・月とファイルID・ファイル名は、Driveのフォルダ構成・ファイル名・ファイル説明に保持します。主任へのメールは送信しません。

## カメラロールについて

「撮影を開始」を押すと、`capture="environment"` を指定した端末の撮影画面を直接開きます。撮影画像はまずブラウザのIndexedDBへ保存されます。オンライン時は直ちに、オフライン時は通信復帰後に、未送信写真を撮影順にGoogle Driveへアップロードします。途中で失敗した写真は端末に残り、画面上のボタンから一括再送できます。各写真には固定の `uploadId` が付き、通常の通信失敗・再送による重複登録を防止します。送信完了後は端末内の画像データを削除します。記録シートとファイル名には、アップロード時刻ではなく実際の撮影時刻を使用します。

撮影方法は「1枚ずつ」と「連続撮影」から選べます。「1枚ずつ」は従来どおり、1枚ごとに確認して端末への保存後に自動アップロードします。「連続撮影」はWeb画面内のカメラを開いたまま撮影し、1枚ごとの確認を挟まず端末へ保存します。最後に写真の一覧を確認し、不要な写真を削除してから一括送信します。連続撮影中に通信状態が変わっても、完了操作までは送信を開始しません。

iPhone・iPadではGAS画面内のカメラ映像が許可されない場合があるため、連続撮影を開始すると端末標準のカメラを直接開きます。「写真を使用」を選ぶと次の撮影のため標準カメラを再度開き、カメラ側で「キャンセル」を選ぶとアプリへ戻ります。iOSがカメラの自動再起動を許可しなかった場合に備え、「次の写真を撮影」ボタンも表示します。他の対応端末では画面内カメラを使用し、利用できなかった場合は端末標準カメラへ切り替えます。

GAS Webアプリの画面自体はネット接続中に読み込む必要があります。いったん撮影画面を開いた状態なら、その後圏外になっても撮りだめできます。未送信写真がある間は、ブラウザの履歴・サイトデータを削除しないでください。

iOS・Safari・PWA・端末OS内部の一時キャッシュや、カメラ権限画面、撮影画面の表示形式まではWebアプリから制御できません。PCでは端末の仕様によりカメラではなくファイル選択画面が開く場合があります。

## 想定環境

- iPhone Safari
- iPad Safari
- Android Chrome
- PC Chrome（カメラ搭載端末）

HTTPSで公開されたGAS Webアプリとして使用し、初回起動時にカメラ利用を許可してください。
